## 3. Semester-Wise Technical Roadmap

### Semester 1 (Current) — Foundations
* **University Subjects:** Programming for Problem Solving (Python), Engineering Mathematics-I, Computer Fundamentals & Linux Lab (`CSE103`), Digital Electronics.
* **Core Skills:** Python syntax & functions, Linux CLI navigation, Git version control, binary/hexadecimal number systems.
* **Projects:** `CSE103` Lab Portfolio Repository, GitHub Profile README.
* **Certifications:** HackerRank Python (Basic) — attempt before Semester 2 begins.
* **Platforms & Habits:** HackerRank (30+ problems), freeCodeCamp intro labs; 3 hours/week of self-study beyond lab hours.

### Semester 2 — Core Computer Science
* **University Subjects:** Data Structures, Object-Oriented Programming (C++/Python), Engineering Mathematics-II, Discrete Mathematics.
* **Core Skills:** Arrays, linked lists, stacks, queues, trees; Python OOP (classes, inheritance, file I/O) and C++ STL basics.
* **Projects:** **DSA Implementation Repository** — build at least 5 core data structures from scratch in Python/C++ with time-complexity documentation.
* **Certifications:** NPTEL *Programming, Data Structures and Algorithms using Python*.
* **Platforms:** LeetCode Easy (50 problems target), GeeksforGeeks DSA track.

### Semester 3 — Intermediate Development & Systems
* **University Subjects:** Database Management Systems (DBMS), Operating Systems, Computer Organization & Architecture, Web Technologies.
* **Core Skills:** Relational databases (MySQL, joins, normalization, indexing), semantic HTML5, modern CSS3, and ES6+ JavaScript.
* **Projects:** **Student Record & Attendance Management System** (Python + MySQL backend with CLI/basic web interface).
* **Certifications:** freeCodeCamp JavaScript Algorithms & Data Structures; HackerRank SQL (Intermediate).
* **Platforms:** HackerRank SQL track, LeetCode (focus on arrays, strings, and hashing).

### Semester 4 — Intermediate-Advanced & Cloud Basics
* **University Subjects:** Design & Analysis of Algorithms (DAA), Computer Networks, Software Engineering, Theory of Computation.
* **Core Skills:** Backend web frameworks (Flask or Django), RESTful API design, authentication (JWT/sessions), Git branching workflows.
* **Personal Passion Project:** **KRMU Campus Event & Club Hub** — a full-stack web application where university clubs can post hackathon/workshop registrations, track RSVPs, and send automated email reminders (built with Django/Flask + PostgreSQL).
* **Certifications:** AWS Cloud Practitioner Essentials (AWS Skill Builder).
* **Platforms:** LeetCode Medium (30 problems target), HackerRank Problem Solving.

### Semester 5 — Specialisation (Track A: Full-Stack Development)
* **University Subjects:** Artificial Intelligence, Compiler Design, Web Engineering / Full-Stack Elective, Cloud Computing.
* **Specialisation Stack:** React.js (hooks, state management), Node.js & Express, MongoDB, Docker basics, REST + GraphQL APIs, deployment (Vercel/Render/AWS EC2).
* **Projects:** 
  1. **Real-Time Collaborative Code/Notes Pad** (React + Node.js + Socket.io + MongoDB) with live demo.
  2. **E-Commerce / SaaS Dashboard** with role-based access control and payment sandbox integration.
* **Internship:** Complete a 2-month summer internship (applications and LinkedIn networking initiated in Semester 4).
* **Certifications:** Meta Front-End or Back-End Developer Professional Certificate (Coursera).

### Semester 6 — Industry Ready & Placements
* **University Subjects:** Machine Learning / Distributed Systems Elective, Information Security, Major Project Phase-I.
* **Capstone Project:** Major team project (3–4 members) solving a real-world campus or industry problem under the mentorship of **Prof. Hemant Billa**.
* **Resume & Portfolio:** 1–2 page ATS-friendly resume featuring 3+ deployed projects, internship experience, and certifications; 5+ pinned GitHub repositories; 300+ LinkedIn connections.
* **DSA & Interview Prep:** 150+ LeetCode problems solved (Easy + Medium mix), system design fundamentals, and weekly mock interviews.
* **Goal:** Secure a full-time Software Engineer / Full-Stack Developer offer via campus placement drives or off-campus referrals.
