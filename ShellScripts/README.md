# Shell Scripts (Q2)

| Script | What it does | Run with |
|--------|--------------|----------|
| [system_report.sh](./system_report.sh) | Prints date, user, kernel, disk and memory details | `bash ShellScripts/system_report.sh` |
| [backup.sh](./backup.sh) | Makes a timestamped `.tar.gz` backup of a folder | `bash ShellScripts/backup.sh Portfolio` |
| [organize_files.sh](./organize_files.sh) | Groups files by extension (preview unless `--apply` is added) | `bash ShellScripts/organize_files.sh <folder>` |

Run the commands from the repository root.
